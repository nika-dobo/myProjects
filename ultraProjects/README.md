# 💎 Ultra Projects

Flagship, high-complexity engineering projects go here (or link from `allWeb.html` to external deployments + GitHub repositories).

When adding a new Ultra project:
1. Place any static/browser demo build in `ultraProjects/<project-name>/` (or deploy full-stack/backend apps externally on Vercel, Render, or Railway).
2. Add a `<div class="project-card">` inside `#ultra .projects-grid` in [`allWeb.html`](../allWeb.html) — project counts and the `Coming Soon` placeholder update automatically.
